# liste-de-courses

Une petite appli web de liste de courses, dans un seul fichier : `index.html`.

## Utilisation

Ouvrez `index.html` dans votre navigateur (double-clic sur le fichier).

- Tapez un article puis cliquez sur **Ajouter** (ou appuyez sur Entrée).
- Cochez la case quand l'article est acheté.
- Cliquez sur **✕** pour le supprimer.

La liste est sauvegardée automatiquement dans votre navigateur.
