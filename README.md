# liste-de-courses

Une petite appli web de liste de courses, dans un seul fichier : `index.html`.

## Utilisation

Ouvrez `index.html` dans votre navigateur (double-clic sur le fichier).

- Tapez un article dans la barre en bas, puis touchez **Ajouter** (ou Entrée).
- Touchez la case ou le nom d'un article quand il est acheté : il descend dans **Dans le panier**.
- Touchez **✕** pour supprimer un article.

En haut, le grand chiffre indique ce qu'il reste à acheter, et la jauge se remplit au fil des courses.
La liste est sauvegardée automatiquement dans votre navigateur. Le mode sombre suit le réglage du téléphone.
